Screen 1 ranks the full usable F&O stock universe. Screen 2 then takes the top ranked stocks from Screen 1 and evaluates actual four-leg IC structures across up to two best expiries per stock, prioritising the 21–35 DTE window. It batches the required option quotes to stay within Zerodha REST limits while still testing multiple available strikes and hedge widths. Short premium legs have a stronger execution threshold than far-OTM hedge legs. Expected-move cushion and credit/max-loss are scored rather than treated as arbitrary pass/fail cliffs. Score weights: IV richness 20%, range quality 15%, expected-move cushion 25%, four-leg liquidity 10%, economics 15%, delta quality 10%, event risk 5%. Normal mode keeps each short leg within +/-0.03 of the target delta, rejects CE/PE delta asymmetry above 0.04, and risk-adjusts extra premium using expected-move cushion.

1. Breakout Screener — independent scan for stocks COILED for a big move (Long Straddle/Strangle candidates)

RankSymbolEntry GateMove ScoreSqueezeADX (base/rising) VolumeNear TriggerATM IVBuyer IV ValueSpread / OISuggestedEvent
Opposite thesis to the Option-Selling screeners above: this looks for a tightening range (Bollinger squeeze), an unusually narrow recent day (NR7), volume drying up (or already picking up), ADX still low or just turning up off a low base, and spot sitting close to a recent range edge — the classic pre-breakout "coiled spring" setup — combined with options that are still relatively CHEAP to buy (low IV vs historical vol). The shortlist is now liquidity-first instead of simply choosing the highest-ATR names. Weights: squeeze 25%, IV cheapness 25%, momentum building 20%, volume setup 15%, proximity to trigger 10%, scheduled event 5%. This is a fully independent module — it does not require the Option-Selling screener above to have been run, and does not predict direction, only that a move is more plausible than usual right now.

    Historical coverage

    Actual stored data · no synthetic history

    On the first successful Kite connection, Stock AI automatically starts a resumable one-year 5-minute backfill for the current F&O universe. Heavy backfill automatically pauses whenever any automated live AI desk is armed, has a live position, or has an unresolved live order; live execution and risk supervision always get priority. Historical setup validation remains underlying-candle evidence, not a historical options-profit backtest.

    Blended success selector

    Historical prior + live option calibration

    Historical setup probability is a conservative prior learned only from underlying candle paths. Live option-success probability comes from completed paper trades. When both validate, the selector blends them and progressively increases the weight of live option evidence. If the long-history archive has not yet reached the minimum coverage gate, its probability is ignored for ranking: the selector uses a validated live-option model if available, otherwise it safely falls back to directional confidence. Neither number is a guaranteed win rate.
